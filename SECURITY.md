# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier unversioned code | No |

## Reporting a vulnerability

Please use GitHub private vulnerability reporting if it is enabled for this repository. If it is not, open an issue asking for a private contact and leave out the technical details.

This is a personal study project, so responses are best effort and no response time is guaranteed.

## Scope

The tool runs locally, takes input from command-line arguments, and has no network access, authentication, or stored data. See [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md) for the latest audit.
